# JDBC - DAO

Projeto simples feito para praticar **JDBC e o padrão DAO em Java**.

Implementei os DAOs de:

* Department
* Seller

O projeto possui operações de consulta, inserção, atualização e remoção de dados no banco.

### Tecnologias

* Java
* JDBC
* MySQL

Projeto desenvolvido durante meus estudos de **Java e banco de dados**.
